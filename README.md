# App Hub de Utilidades (Android - Java)

Este projeto consiste no desenvolvimento de um aplicativo Android em Java que funciona como um hub de ferramentas, reunindo múltiplas funcionalidades em um único app. O objetivo principal é praticar conceitos fundamentais do desenvolvimento Android aprendidas na aula de Programação de Dispositivos Móveis II

## Funcionalidades

O aplicativo possui um menu principal que permite acessar quatro módulos diferentes:

*  **MegaSena**
  Geração de números aleatórios simulando apostas da Mega-Sena.

*  **IMC (Índice de Massa Corporal)**
  Cálculo do IMC com base em peso e altura, exibindo a classificação correspondente.

*  **Jokenpô (Pedra, Papel e Tesoura)**
  Jogo contra o computador no formato melhor de 3, com controle de placar e opção de reiniciar a partida.

*  **Questionário da Felicidade**
  Um sistema de avaliação baseado em hábitos diários, que calcula um índice de felicidade utilizando pontuação ponderada**.
